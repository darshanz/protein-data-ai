# Protein data AI

A collection of projects (study notes) on the application of AI/ML to problems in protein bioinformatics, including structure prediction, folding, and binding.

## Overview
My study notes and experiments with:
- Processing DNA, RNA, and protein data
- Applying deep learning to predict protein secondary structure
- Analyzing 3D protein structures from the PDB
- Predicting protein-ligand binding affinity
- Running state-of-the-art folding models like ColabFold

## Projects

| Project | Description | Key Skills |
|---------|-------------|------------|
| [01: Sequence Analysis](01_sequence_analysis/) | Translating DNA to protein and basic sequence manipulation | Biopython, Sequence Biology |
| [02: Secondary Structure Prediction](02_secondary_structure/) | Predicting protein secondary structure from sequence | CNNs, PDB Data Processing |
